## 16.1 What changed in the kit itself

- `files/` refreshed from the deployed remote (sanitized, see `tools/privacy-scan.sh`).
- New files: logind drop-in, `tv-guard.service`, `tv-guard.timer`, `tv-guard-fw.sh`, `tv-guard-check.py`.
- Changed: `tv-net-isolate.sh` (calls the guard firewall), `waydroid_base.prop` (ARM bridge line),
  `tv-remote.service`, `index.html`, `tv-remote.py`.
- Tools: `privacy-scan.sh` (new), `deploy-remote.sh` (new; deploys from a **filled** copy), `fill-placeholders.sh`
  (values are escaped; `__ANDROID_IP__` is the Waydroid container address, `__VPN_ROUTER_IP__` is optional).
- The stream-scraper app shortcut in the remote is replaced by a placeholder; channel-list app IDs are placeholders.
- Layout: the single long README is split into `docs/` chapters; the README is now a front page.

## 16.2 Deliberately not documented

- Owner-specific names, network addresses, device lists, certificate material and tokens: they stay on the
  owner's PC and TV host, never in this repo.
- Specific third-party apps that the reference box removed or did not install.
